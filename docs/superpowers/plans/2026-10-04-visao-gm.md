# Visão do GM (#18) Implementation Plan

**Goal:** Tela `/gm`, sem link na navegação e sem senha, com data da campanha, todos os hunters (avaliação e ganhos), todas as missões com estado (agendadas marcadas), erros do JSON por campo e o Convite para copiar.

**Spec:** Issue #18, parte de #9. ADR 0001 e 0002.

## Decisões

- Caminho: `/gm`. O portão do app deixa a Visão do GM abrir sem hunter escolhido e também quando o JSON está inválido (sem versão válida), para o GM ver o erro.
- Mensagens de erro do schema passam para português com `ajv-i18n` (pendência do #12).
- Com versão válida guardada e JSON novo inválido: "Os jogadores continuam vendo a última versão válida." Sem versão válida: "Os jogadores não conseguem abrir a campanha até o JSON ser corrigido."
- Convite = `<origem do app>/?campanha=<URL do JSON codificada>`, num campo só leitura com botão "Copiar" (área de transferência; se falhar, o texto do campo fica selecionado para copiar à mão).
- Missões agendadas aparecem com a etiqueta "Agendada" e o horário relativo de publicação.

## Interfaces

- campaign.js: `gmView(campaign) -> { date, hunters: [{ hunter, earnings }], missions: [MissionView + { scheduled }] }`
- sync.js: `inviteLink(appOrigin, campaignUrl) -> string`; `sync.getCampaignUrl() -> string | null`
- store: `campaignUrl` no estado.

## Tasks

1. TDD: erros em português; `gmView` (todos os hunters com ganhos, todas as missões, agendada marcada); `inviteLink` (ida e volta com `readInvite`); `getCampaignUrl`.
2. Rota `/gm`, portão, tela.
3. `pnpm test`, `pnpm lint`, `pnpm build`; Chrome headless.
